# 期末粥加速器

面向大学生期末周冲刺的本地 AI 学习工作台。用户围绕单门课程导入资料、完成快速摸底、生成复习主线，并在刷题、模拟卷、笔记和错题回顾中持续调整学习策略。

## V1 目标

V1 用于实验室演示，优先验证“课程资料理解 -> 快速摸底 -> 复习计划 -> 练习反馈 -> 动态调整”的学习闭环。

已规划的核心模块：

- 课程空间：多课程切换、考试信息、目标分数和每日可用时间。
- 资料库：本地资料导入入口与可追溯的资料引用。
- 复习主线：按知识点优先级组织的每日学习任务。
- 刷题练习：题目作答、即时讲评与掌握度更新。
- 模拟卷：限时组卷、评分与错题沉淀。
- 笔记：关联知识点的轻量复习记录。
- 错题本：错误归因、复练和回顾。
- AI 伴学：理解自然语言调整需求，生成待确认的计划调整提案。

## 技术架构

```text
React + TypeScript + Vite
        |
        | 本地 HTTP API
        v
FastAPI + SQLite + 本地文件库
        |
        v
OpenAI 兼容模型适配层
```

- 前端负责课程工作台、学习交互与本地展示状态。
- 后端负责本地 API、资料解析、学习记忆、模型配置与后续 Agent 编排。
- SQLite 保存课程、计划、作答、错题、笔记和调整提案。
- 课程资料与解析产物保存在本机文件库中。

## 本地运行

前端：

```bash
cd web
npm install
npm run dev
```

后端：

```bash
cd backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

前端默认通过 Vite 启动；后端默认监听 `http://127.0.0.1:8000`。

## V1 边界

- V1 默认在 Windows 本机运行，不包含登录、云同步、多人协作和公开部署。
- 网址资料仅保存链接、备注和用户摘录，不自动抓取网页正文。
- 外部联网检索默认关闭。
- 模型调用通过用户配置的 GPT、DeepSeek、GLM 或 OpenAI 兼容接口完成；API Key 仅应保存在本机。
